# CNIC cards — 2 pages, fronts and backs matched by CNIC number

Six national ID cards, each **front paired with its own back**. Nothing is mixed: every front is numbered 1–6 and
its back carries the same number, the same name and the same CNIC number, so you can check the pair at a glance.

Cards are laid out A4 at **exact ID-1 size: 85.6 × 53.98 mm**.

## Printing

1. Open the PDF, choose **A4**, and set scaling to **100% / Actual Size** (turn OFF "Fit to page" / "Shrink oversized pages").
2. For the duplex files: enable **Print on both sides → Flip on long edge** (book style) — or use the short-edge file if that is the only option your printer offers.
3. Plain A4 or slightly heavier paper. Cut along the faint grey guides.
4. On the mirrored back sheet the numbers read 2, 1 / 4, 3 / 6, 5 — that is correct for flipping, not a mix-up. The number on each back always matches the number on its front.

If a card comes out a millimetre or two off, print page 1 only, hold it against a real card, and confirm the scale before the double-sided run.

## Source quality

Each image was deskewed, cropped to the plastic outline, toned to match the others and resampled to the real
85.6 × 53.98 mm aspect, so cards photographed from different angles still print the same size.
Muhammad Aman's pair was supplied as a photocopy scan, so it prints lighter and softer than the other five — that
comes from the original image, not this layout.
