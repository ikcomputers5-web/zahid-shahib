# CNIC cards — 2-page, double-sided print file

Six national ID cards (front + back), laid out A4 at **exact ID-1 size: 85.6 × 53.98 mm**.

## Files

| File | Use |
|---|---|
| `CNIC-2page-double-sided-flip-long-edge.pdf` | **Main file.** Page 1 = all fronts, page 2 = matching backs, mirrored so duplex "flip on long edge" pairs each back with its front. |
| `CNIC-2page-double-sided-flip-short-edge.pdf` | Same, mirrored for printers that flip on the short edge. |
| `preview-page-1.jpg` / `preview-page-2.jpg` | Screen previews of the two pages. |
| `all-cards-preview.jpg` | Each card's front beside its back, for a quick check. |

## Printing

1. Open the PDF, choose **A4**, and set scaling to **100% / Actual Size** (turn OFF "Fit to page" / "Shrink oversized pages").
2. Enable **Print on both sides → Flip on long edge** (book style). If your printer only does short edge, use the `short-edge` file instead.
3. Plain A4 (legal/thick paper is easier to cut). Do not select borderless photo mode — a small margin is fine.
4. Cut along the faint grey guides, then trim inside the plastic outline.

If a card comes out a millimetre or two off, print page 1 only, hold it against an actual card, and check the scale before doing the duplex run.
